# Monitor móvil Profuturo Fondo 3

Aplicación web móvil del modelo final OLS rolling 90.

## Despliegue en Streamlit Community Cloud

- Repositorio: `rldaqp/afp-fondo3-monitor`
- Rama: `streamlit-monitor-ols`
- Archivo principal: `streamlit_mobile/streamlit_app.py`

La carpeta incluye su propio `requirements.txt`.

## Funciones

- Solo monitorear el mercado.
- Registrar que se está dentro del fondo.
- Registrar una salida.
- Descargar SBS, Yahoo Finance y BCRP.
- Estimar el valor cuota hasta la fecha de mercado más reciente.
- Mostrar la señal provisional o completa.
- Mostrar un gráfico de retorno para cada componente con eje central en cero.
- Mostrar la evolución de una operación y la auditoría del modelo.

La estimación es informativa y no garantiza rentabilidad.
